# Contributing

Thanks for your interest! The project is in its **design stage (pre-alpha)**, so the most useful contributions right now are:

- Feedback on the design in [ROADMAP.md](ROADMAP.md) — open an issue.
- Real-world data on LLM API latency and cost, which feeds the latency and cost models.
- Examples of LLM/agent trading strategies you would like to backtest.

When code lands, pull requests should describe the problem, the approach and how it was tested. Please keep each PR focused on one change.
